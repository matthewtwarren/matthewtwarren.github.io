{{< lead >}}
A running log of walks, runs and rides, each mapped from its GPX track.
{{< /lead >}}

Every map below is drawn straight from a GPX file — distance, duration and ascent are
calculated in your browser. To add a route I just upload one `.gpx` file to the
`content/routes/` folder (on GitHub, **Add file → Upload files**); a new card appears
automatically once the site rebuilds.

Files are named `YYYY-MM-DD-short-title.gpx` (for example `2026-08-24-kinder-scout.gpx`),
which keeps them in date order and gives each route a date and title even when the track
itself carries none.
